### Lista de Tarefas (To-Do List)

### Sobre o Projeto:

Uma aplicação web desenvolvida para o gerenciamento de tarefas do dia a dia, focada em organizar atividades por grau de importância e urgência. O projeto foi construído para consolidar os fundamentos de lógica de programação, manipulação do DOM e estruturação de interfaces web.

### Tecnologias Utilizadas

- HTML5: Estruturação semântica de blocos e formulários da aplicação.
- JavaScript (Vanilla): Lógica de programação, manipulação de arrays, manipulação dinâmica do DOM e funções de CRUD.

### Funcionalidades Principais

- Adicionar Tarefas: Inclusão rápida de novas atividades na lista por meio de campos de entrada de dados.
- Editar Tarefas: Atualização do texto de qualquer atividade diretamente na interface, com feedback em tempo real.
- Remover Tarefas: Exclusão de registros que já foram concluídos ou não são mais necessários.
- Movimentação Bidirecional: Capacidade de transicionar uma atividade entre diferentes níveis de importância com apenas um clique.

### Tipos de Lista

- Tarefas Urgentes: Destinadas às atividades prioritárias que precisam ser concluídas com maior rapidez. Possuem botões dedicados para edição, exclusão e rebaixamento para o nível comum.

- Tarefas Comuns: Destinadas às atividades do dia a dia com menor grau de urgência imediata. Também contam com suporte completo a edição, exclusão e promoção direta para a lista de urgentes.
